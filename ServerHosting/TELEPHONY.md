# Телефония Плюсофон (Plusofon) — подключение

Раздел админки **«Телефония»** соединяет клиента с водителем/оператором,
делает Flash Call для подтверждения номера и ведёт журнал звонков.

## 1. Что взять в личном кабинете Плюсофон

1. Войдите в ЛК Плюсофон → раздел **API / Интеграции**.
2. Включите доступ к API и создайте приложение — получите:
   - **API-токен** (Bearer token);
   - **Client ID** — идентификатор приложения (передаётся заголовком `Client`);
   - **Номер АТС** — ваш подключённый номер, с которого идут звонки (caller number).

## 2. Настройка в админке

Админка → **Телефония**:

| Поле | Значение |
|---|---|
| Включена | галочка |
| Base URL | `https://api.plusofon.ru/rest/v1` (подберётся автоматически диагностикой) |
| Client ID | из ЛК |
| API-токен | из ЛК |
| Номер АТС | ваш номер в формате `+7XXXXXXXXXX` |
| Метод соединения | `/call/callback` |
| Метод Flash Call | `/flash-call/create` |
| Метод баланса | `/customer/balance` |

Сохраните → нажмите **«Проверить и настроить»** (Диагностика подключения).

## 3. Диагностика подключения

Кнопка проверяет и показывает таблицей:

- **cURL** на хостинге (основной транспорт) и `allow_url_fopen` (резерв);
- заданы ли токен, Client ID и номер АТС;
- ответ API по нескольким известным адресам Плюсофон
  (`api.plusofon.ru/rest/v1`, `restapi.plusofon.ru/api/v1`, `api.plusofon.ru/api/v1`)
  и методам баланса.

Найденная рабочая комбинация **сохраняется в настройки автоматически**.

## 4. Расшифровка ошибок

| Что показано | Причина и решение |
|---|---|
| `cURL: нет` и `allow_url_fopen: выкл` | Хостинг блокирует исходящие HTTP. Включите расширение cURL в панели хостинга |
| HTTP 401 / 403 | Неверный API-токен или Client ID — перевыпустите в ЛК |
| HTTP 404 по всем адресам | Изменились методы API — уточните актуальные пути в ЛК и впишите в поля «Метод …» |
| `Нет соединения` / HTTP 0 | Хостинг не пускает наружу к api.plusofon.ru — попросите поддержку открыть исходящие соединения на 443 |
| HTTP 200, но звонка нет | Проверьте, что «Номер АТС» действительно подключён к вашему ЛК и разрешён как caller ID |

## 5. Сценарии в системе

- **Звонок при подаче** — включается галочкой «Звонить клиенту при прибытии
  водителя»: система соединяет водителя и клиента без раскрытия номеров.
- **Flash Call** — подтверждение номера входящим звонком вместо SMS.
- **Ручное соединение** — форма «Тестовое соединение» (два номера).
- **Журнал звонков** — статусы, длительность, ссылки на записи (если включена
  запись у провайдера), внешние ID для сверки с ЛК.

## 6. Webhook статусов

Дайте Плюсофону адрес для событий (в ЛК → Webhooks):

```
https://taxi.event72.ru/api/telephony/webhook.php?secret=ВАШ_СЕКРЕТ
```

Секрет задаётся в том же разделе админки. Webhook обновляет статус, длительность
и ссылку на запись в журнале звонков.
