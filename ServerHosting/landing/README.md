# Лендинг «Работа водителем» — установка на домен первого уровня

`apply.html` — готовая страница-анкета. Работает как статический файл на любом
хостинге/домене: отправляет данные на API вашего сервера (`taxi.event72.ru`).

## Установка

1. Скопируйте `apply.html` на свой сайт (например, `https://вашдомен.ру/apply.html`
   или переименуйте в `index.html` для отдельного поддомена).
2. Внутри файла, в блоке `<script>`, проверьте адрес API:
   ```js
   var API = 'https://taxi.event72.ru/api/applications.php';
   ```
3. Разрешите кросс-доменные запросы на стороне API: в `config.local.php`
   на taxi.event72.ru укажите домен лендинга:
   ```php
   define('CORS_ORIGIN', 'https://вашдомен.ру');
   ```
   (по умолчанию стоит `*` — работает сразу, но лучше ограничить своим доменом)

## Что происходит после отправки

1. Анкета с 6 фото попадает в таблицу `driver_applications` (файлы — в приватную
   папку `uploads/applications`, прямой доступ по URL закрыт).
2. Диспетчеры и администраторы получают уведомление «Новая анкета водителя».
3. В админке появляется раздел **«Соискатели»**: фото-превью, статусы
   (Новая → На рассмотрении → Связались → Одобрена/Отклонена).
4. Кнопка **«Одобрить и создать аккаунт»** заводит водителя: пользователь с ролью
   `driver`, профиль авто, фото переносятся в карточку. Логин (телефон) и
   сгенерированный пароль показываются администратору один раз — передайте их водителю.

## API (если делаете свою форму)

`POST https://taxi.event72.ru/api/applications.php` — `multipart/form-data`, публичный.

| Поле | Обязательное | Примечание |
|---|---|---|
| `lastName`, `firstName`, `phone` | да | телефон нормализуется к +7… |
| `carBrand`, `carModel`, `licensePlate` | да | |
| `middleName`, `city`, `experienceYears`, `licenseNumber`, `licenseExpiry`, `carColor`, `carYear`, `comment`, `childSeatNote` | нет | |
| `hasChildSeat` | нет | `1` — есть детское кресло |
| `photo_license`, `photo_selfie`, `photo_car_front`, `photo_car_back`, `photo_car_left`, `photo_car_right` | да | JPEG/PNG/WebP до 6 МБ |

Ответ `201`: `{"ok":true,"id":"…","message":"Анкета принята…"}`;
ошибки валидации — `422` с полем `errors` (список).
Антиспам: не более 3 анкет с одного номера в сутки.
