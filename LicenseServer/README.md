# Сервер лицензий TaxiTyumen

Автономный сервер лицензий на PHP 7.4+ + MySQL для лицензирования серверной
части системы такси. Размещается на отдельном домене (taxi.license-prog.ru)
на виртуальном хостинге jino.ru.

> На домене сейчас обнаружен PHP 7.4.33. Код совместим с PHP 7.4, но эта
> версия снята с поддержки. Для безопасного production в панели jino.ru
> переключите домен на **PHP 8.2 или PHP 8.3**.

## Файлы

| Файл | Назначение |
|---|---|
| `index.php` | Вход с корня домена → админ-панель |
| `install.php` | Одноразовая установка и диагностика jino.ru |
| `license-core.php` | Ядро: БД, TOTP 2FA (RFC 6238), защита от брутфорса |
| `license-api.php` | Публичный API: проверка и активация лицензий |
| `license-admin.php` | Админ-панель с 2FA: управление лицензиями |
| `assets/qrcode.min.js` | Локальная генерация QR (секрет 2FA не уходит третьим лицам) |

## Установка на jino.ru

### 1. Переключите PHP в jino.ru

На живом домене обнаружен `PHP/7.4.33`. Код теперь совместим и с ним, но
PHP 7.4 снят с поддержки и небезопасен для production. В панели jino.ru
выберите для домена **PHP 8.2 или PHP 8.3**.

### 2. Создайте базу MySQL

В панели jino.ru создайте базу данных (например, `taxi_licenses`) и
пользователя с полным доступом к ней.

### 3. Загрузите весь каталог

Загрузите **всё содержимое** `LicenseServer/` в корень домена
`taxi.license-prog.ru`, включая `.htaccess`, `install.php` и папку `assets/`.

### 4. Запустите установщик

Откройте `https://taxi.license-prog.ru/install.php`, введите реквизиты MySQL
и придумайте пароль администратора (минимум 12 символов). Установщик:

- проверит PHP и расширения;
- проверит соединение с базой;
- создаст `license.local.php` со случайным 96-символьным секретом;
- захэширует пароль администратора;
- создаст таблицы и `setup.lock`;
- перенаправит в админку.

Если `license.local.php` уже создавался вручную, установщик его не перезапишет.
При ошибке удалите файл через файловый менеджер jino.ru и запустите установку снова.

### 5. Первый вход

Откройте `https://taxi.license-prog.ru/` (корень теперь сам перенаправляет в админку).

При первом входе:
1. введите логин и пароль из `license.local.php`;
2. сервер покажет QR-код и секретный ключ настройки;
3. отсканируйте QR в Google Authenticator / FreeOTP (или введите ключ
   вручную с именем `TaxiLicense`, тип «По времени»);
4. введите 6-значный код для подтверждения.

QR строится локальным `assets/qrcode.min.js`: секрет не отправляется
стороннему сервису генерации QR. После первого
подтверждения он хранится в MySQL в зашифрованном виде и переживает выход,
очистку cookie и перезагрузку сервера.

### 6. Если потерян телефон с 2FA

Временно добавьте в `license.local.php`:

```php
define('LIC_RESET_2FA', true);
```

Откройте `license-admin.php` один раз, затем **сразу удалите эту строку**.
При следующем входе сервер покажет новый QR-код.

### 7. Защита от брутфорса

- 5 неудачных попыток пароля **или 2FA** → блокировка на 15 минут для пары логин+IP;
- счётчик сбрасывается только после полного успешного входа (пароль + TOTP);
- все попытки пишутся в таблицу `admin_login_attempts`.

## API

### POST /license-api.php?action=check

Тело: `{"key":"XXXXX-XXXXX-XXXXX-XXXXX-XXXXX","domain":"taxi.example.ru"}`.

Проверка лицензии (вызывается сервером такси раз в сутки). POST используется,
чтобы ключ не попадал в URL и access-логи.

Ответ при действующей лицензии:
```json
{
  "valid": true,
  "plan": "standard",
  "maxDrivers": 50,
  "expiresAt": "2027-09-13 00:00:00",
  "customerName": "ИП Иванов",
  "nextCheckAfter": 86400
}
```

Ответ при истёкшей лицензии (HTTP 403):
```json
{
  "valid": false,
  "reason": "expired",
  "message": "Срок лицензии истёк 2026-09-13 00:00:00"
}
```

### POST /license-api.php?action=activate

Тело: `{"key":"XXXXX-XXXXX-XXXXX-XXXXX-XXXXX","domain":"taxi.example.ru"}`

Первый домен, активировавший ключ, привязывается к лицензии навсегда.

### GET /license-api.php?action=health

Проверка доступности сервера.

## Интеграция с сервером такси

На сервере такси в `config.local.php`:

```php
define('LICENSE_KEY', 'ABCDE-FGHJK-LMNPR-STUVW-XYZ23');
define('LICENSE_SERVER', 'https://taxi.license-prog.ru');
```

Или введите ключ в админке: **«Лицензия» → «Ключ лицензии» → Активировать**.

### Как работает проверка

1. `_bootstrap.php` вызывает `LicenseClient::ensureChecked()` при каждом запросе;
2. если с последней проверки прошло >24 часов — отправляется запрос на сервер лицензий;
3. при ответе `valid: true` — API работает;
4. при ответе `valid: false` — все API-эндпоинты возвращают HTTP 403 с описанием;
5. при недоступности сервера лицензий — льготный период 3 дня;
6. админка остаётся доступной всегда, чтобы можно было ввести новый ключ.

### Блокировка при истечении

Когда лицензия истекает:
- все мобильные приложения перестают получать данные (API отвечает 403);
- в админке загорается красное предупреждение;
- поле ввода нового ключа остаётся доступным.

После ввода действующего ключа API мгновенно возобновляет работу.

## Управление лицензиями

В админке сервера лицензий:

- **Выдать**: клиент, email, домен, тариф (trial/standard/pro), макс.
  водителей, срок в месяцах;
- **Продлить**: +N месяцев от текущей даты;
- **Приостановить** / **Возобновить**;
- **Отозвать** — лицензия навсегда недействительна;
- **Удалить** — полная очистка записи.

## Безопасность

- ключи лицензий: 25 символов из алфавита без похожих символов (0/O, 1/I, S/5);
- полный ключ показывается только один раз, в MySQL хранится HMAC-SHA256-хэш;
- доменная привязка: ключ работает только на домене, который его активировал;
- TOTP 2FA (RFC 6238): 6-значные коды, окно ±30 секунд;
- брутфорс-защита: 5 попыток → 15 минут блокировки;
- LIC_SECRET: HMAC-подпись ключей и сессий;
- все действия журналируются в `license_events`.

## Настройка базы на jino.ru

Таблицы создаются автоматически при первом обращении к `license-api.php`
или `license-admin.php`. Дополнительно запускать SQL-скрипты не нужно.
