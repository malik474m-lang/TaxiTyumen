# Встроенный SMS-шлюз (Android + сервер)

SMS сервиса отправляет **обычный Android-телефон с SIM-картой**, а не платный
внешний провайдер. Сервер ставит сообщение в очередь, телефон забирает задание
по интернету, отправляет SMS и подтверждает результат — в админке видно, что
сообщение доставлено.

```
Сервер (PHP)                     Телефон-шлюз (Android)
  очередь sms_gateway_queue         приложение TaxiSmsGateway
        │  1. GET  ?action=poll   ◄──── опрос каждые N секунд
        │  2. отдаёт задания      ────►
        │                               3. SmsManager отправляет SMS
        │  4. POST action=ack     ◄──── подтверждение (успех/ошибка)
        ▼
  статус sent / failed, видно в админке
```

## Что нужно

* Телефон на Android 8.0+ с SIM-картой и **безлимитными SMS** в тарифе;
* Постоянный интернет на телефоне (Wi-Fi достаточно);
* Питание от зарядки — телефон работает круглосуточно.

## Настройка за 5 минут

1. **Сервер:** админка → раздел **«SMS-шлюз»** → галочка «Включить SMS-шлюз»
   → «Сохранить» → кнопка **«Выдать новый токен»** (токен показывается один раз).
2. **Сборка приложения** (на компьютере):
   ```powershell
   powershell -ExecutionPolicy Bypass -File build-smsgateway.ps1
   ```
   Установите на телефон файл `...-Signed.apk`.
3. **Телефон:** откройте приложение → впишите адрес сервера
   (`https://taxi.event72.ru`) и токен → **«Проверить связь»** → должно быть
   «Сервер отвечает, шлюз включён».
4. Нажмите **«Запустить шлюз»** и разрешите отправку SMS.
5. В админке нажмите **«Отправить тест»** — через несколько секунд сообщение
   придёт на указанный номер, а в журнале появится статус «Отправлено».

## Важные настройки телефона

Android агрессивно усыпляет фоновые приложения. Обязательно:

* **Настройки → Батарея → Экономия заряда для приложения → Без ограничений**
  (на Xiaomi: «Автозапуск» включить, «Ограничения фоновой активности» снять);
* приложение держать **открытым** (экран не гаснет — это делает само приложение);
* отключить оптимизацию батареи для приложения в списке исключений.

## Как это работает в системе

Пока шлюз **включён**, все SMS сервиса (коды входа, восстановление пароля,
уведомления пассажирам) идут через телефон. Если шлюз **выключен**, система
автоматически возвращается к sms.ru — ничего перенастраивать не нужно.

Надёжность:

* задание, которое телефон взял, но не подтвердил за 2 минуты, автоматически
  возвращается в очередь;
* до 3 попыток отправки, затем статус «Ошибка» и кнопка «Повторить» в админке;
* суточный лимит SMS настраивается (защита от блокировки SIM оператором);
* смена токена мгновенно отключает старый телефон.

## Ограничения

* Операторы связи не любят массовые рассылки с обычных SIM — держите
  разумный суточный лимит (например, 100–300 SMS);
* сообщения приходят с обычного номера SIM-карты, а не с буквенного имени
  отправителя (для имени нужен sms.ru);
* телефон должен быть в сети: при потере связи сообщения копятся в очереди
  и уйдут после восстановления.
