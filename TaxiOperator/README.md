# Пульт оператора (Windows) — установка, работа, SIP-телефония

Настольное приложение диспетчера службы такси: приём звонков клиентов,
создание заказов, назначение водителей, контроль смены.
Сервер: `https://taxi.event72.ru/api/`.

---

## 1. Сборка приложения

Нужен **.NET SDK 10** (см. `TaxiDriver/ANDROID.md`, ШАГ 0–1 — там же ставится .NET).
Android SDK для оператора **не требуется**.

```powershell
dotnet publish TaxiOperator/TaxiOperator.csproj -c Release -r win-x64 --self-contained false
```

Готовое приложение: `TaxiOperator\bin\Release\net10.0-windows10.0.17763.0\win-x64\publish\TaxiOperator.exe`
Папку `publish` можно целиком скопировать на компьютер диспетчера.

**Полностью автономная сборка** (не требует .NET на компьютере диспетчера, ~150 МБ):
```powershell
dotnet publish TaxiOperator/TaxiOperator.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

**Сборка без телефонии** (если SIP не нужен или мешает сборке):
```powershell
dotnet publish TaxiOperator/TaxiOperator.csproj -c Release -p:DisableSip=true
```
Приложение соберётся полностью рабочим, панель телефонии покажет
«SIP-телефония отключена в этой сборке».

## 2. Вход

Логин — телефон и пароль учётной записи с ролью **оператор**
(создаёт администратор в разделе «Операторы»). Демо: `+79001234568` / `Operator123!`.

## 3. Рабочий экран

| Зона | Назначение |
|---|---|
| Слева сверху | **Софтфон**: статус линии, входящий номер, таймер разговора |
| Слева | Форма нового заказа: телефон, имя, адреса с подсказками, тариф, опции |
| Центр | Счётчики (активные, ожидают, водители онлайн) и таблица заказов |
| Справа | Детали выбранного заказа, назначение водителя, отмена, баланс/штраф |

Список заказов и уведомления обновляются каждые 3 секунды.

## 3.1. Брендинг из админки

Пульт автоматически подхватывает оформление из админки — **ничего не нужно
прописывать в приложении**:

| Что берётся | Откуда в админке |
|---|---|
| Название сервиса («НАШЕ Такси») в заголовке окна, экране входа и панели | «Бренд сервиса» → Название |
| Подпись приложения («Диспетчерская», «Пульт оператора») | «Брендинг» → приложение **operator** |
| Акцентный цвет (заголовки, суммы, номер звонящего) | «Брендинг» → operator → Основной цвет |
| Телефон поддержки в панели оператора | «Брендинг» → operator (или «Бренд сервиса») |

- Бренд загружается **до показа окна входа**, затем обновляется каждые 5 минут —
  смена названия или цвета в админке применяется у операторов без переустановки.
- Значения кэшируются локально (`%APPDATA%\TaxiTyumen\branding-operator.json`),
  поэтому при недоступном интернете пульт стартует с последним оформлением.

## 3.1. Маршрут заказа: промежуточные адреса и «туда-обратно»

- **Промежуточные адреса** добавляются кнопкой «+ Добавить» и соблюдаются
  строго в указанном порядке: подача → точка 1 → точка 2 → назначение.
- **«Туда и обратно»** — галочка возврата на адрес подачи. Обратный путь
  проходит через те же промежуточные точки в обратном порядке.
- Предварительная стоимость считается по полному маршруту, поэтому она
  совпадает с итоговой ценой заказа.
- Клиент сохраняется в базе автоматически: при повторном вводе номера
  подставляются имя и последний адрес подачи.

## 3.1.0. Промежуточные адреса и зонная цена

Когда действует фиксированная цена зоны, она остаётся **базой** заказа
(путь до конечного пункта внутри зоны), а каждый промежуточный адрес
оплачивается **дополнительно по километражу тарифа**:

```
Пункт А (подача) → Б (промежуточный) → В (конечный)
                    └── А→Б: км × цена/км ──┘  +  цена зоны Б→В
```

Пример: цена зоны 250 ₽, путь А→Б 3,2 км по тарифу 10 ₽/км = 32 ₽.
Итого: 250 + 32 = **282 ₽**.

В строке расчёта наценка видна отдельно: «через 1 точк(и) · адрес +32 ₽».

### Минимальная цена промежуточного адреса

В админке «Зоны и цены» настраивается:

- **Минимальная цена за адрес, ₽** — если по километражу выходит меньше,
  применяется минимум (за каждый промежуточный адрес);
- **Режим расчёта**:
  - «Минимум **ИЛИ** километраж» — берётся большее из двух;
  - «Минимум **ПЛЮС** километраж» — километраж добавляется к минимуму.

Пример (минимум 50 ₽, тариф 10 ₽/км):

| Ситуация | ИЛИ | ПЛЮС |
|---|---|---|
| 0,3 км, 1 адрес (км=3 ₽) | 50 ₽ | 53 ₽ |
| 5,0 км, 1 адрес (км=50 ₽) | 50 ₽ | 100 ₽ |
| 3,0 км, 2 адреса (км=30 ₽) | 100 ₽ | 130 ₽ |

Минимум = 0 отключает ограничение и возвращает чистый расчёт по километражу.

Без промежуточных адресов наценка не начисляется. Вне зоны заказ
по-прежнему считается по километражу всего маршрута.

## 3.1.1. Предварительные заказы

- Галочка **«Предварительный заказ»** открывает выбор даты и времени подачи.
- Минимум за 5 минут до подачи, максимум на 30 дней вперёд.
- К стоимости добавляется **наценка за предзаказ** из тарифа
  (админка → «Тарифы» → «Наценка за предзаказ, ₽»).
- Предварительный заказ **не рассылается водителям сразу**: он появляется
  в их ленте за 30 минут до времени подачи.
- Время подачи видно в списке заказов, в деталях и у водителя в карточке.

## 3.2. Карта автопарка в пульте

Кнопка **«Карта автопарка»** рядом с «Обновить список» открывает окно с картой:

- показываются **только водители в сети**, ушедшие в offline исчезают;
- метки двигаются в реальном времени, обновление каждые 5 секунд;
- цвет метки: зелёный — свободен, оранжевый — едет к клиенту, синий — в поездке;
- в карточке машины видны **скорость (км/ч)** и признак «Выполняет заказ»;
- справа список машин: клик центрирует карту и открывает карточку водителя;
- флажок **«Следить за выбранной машиной»** удерживает камеру на выбранном авто;
- центр карты и город берутся из админки (**«Бренд сервиса» → город/координаты**),
  ключ Яндекс Карт — с сервера (`api/map-config.php`), в дистрибутив не вшивается.

Карта использует компонент Microsoft Edge WebView2, который предустановлен
в Windows 10/11. Если он отсутствует, окно сообщит об этом и продолжит
работать как список водителей в сети; runtime ставится с сайта Microsoft
(«Evergreen Standalone Installer»).

## 4. SIP-телефония (гарнитура на ПК)

### Что нужно от АТС
Внутренний номер (SIP-аккаунт) у вашего провайдера или на своей АТС:
Asterisk / FreePBX / 3CX, либо облачные Mango Office, Zadarma, Telphin и т.п.
От провайдера нужны три параметра: **сервер**, **логин (номер)**, **пароль**.

### Настройка (один раз на каждом рабочем месте)
1. Подключите USB- или Bluetooth-гарнитуру **до запуска** программы.
2. В приложении: панель «Телефония» → **Настройки**.
3. Включите «Включить телефонию», заполните сервер / номер / пароль.
4. Выберите **микрофон** и **наушники** гарнитуры из списка устройств Windows
   (или оставьте «По умолчанию»).
5. Опции:
   - **Автоответ** — звонок принимается сразу (режим «всегда в наушниках»);
   - **Подставлять номер звонящего в новый заказ** — телефон клиента
     автоматически попадает в форму заказа, курсор переходит в поле адреса.
6. «Сохранить и подключиться» → статус сменится на «На линии · 100@sip.example.ru».

Настройки хранятся локально: `%APPDATA%\TaxiTyumen\sip.json` (у каждого оператора свои).

### Работа со звонком
- **Входящий**: окно пульта поднимается наверх, показывается номер, кнопка
  **«Ответить»**; телефон клиента уже подставлен в форму заказа — сразу
  спрашивайте адрес и оформляйте.
- **«Сброс»** — завершить разговор, **«Микр.»** — отключить микрофон (mute).
- **Исходящий**: введите номер в поле рядом и нажмите **«Позвонить»** —
  удобно перезванивать клиенту или водителю.
- Во время разговора идёт таймер; создавать заказ можно не прерывая звонок.

### Если звонки не проходят
| Симптом | Решение |
|---|---|
| «Ошибка регистрации: 401/403» | Неверный логин/пароль внутреннего номера |
| «Ошибка регистрации: timeout» | Проверьте адрес сервера и что порт 5060/UDP не блокирует брандмауэр или роутер |
| Регистрация есть, звука нет | Проверьте выбор устройств в настройках; для NAT-сетей включите на АТС SIP ALG/STUN или используйте VPN до АТС |
| Слышно с эхом | Выберите именно устройства гарнитуры, а не «Динамики ноутбука» |
| Нет списка устройств | Гарнитура подключена после запуска — перезапустите приложение |

Технология: SIP (RFC 3261) поверх UDP, аудио RTP (G.711 A/µ-law),
библиотека SIPSorcery. Видеозвонки не поддерживаются.

## 5. Смена оператора

Кнопки «Начать смену» / «Завершить смену» — учёт рабочего времени и
выработки (созданные и завершённые заказы) отображается в админке.
