# Офлайн-карта водителя: OpenStreetMap → PMTiles

Своя векторная карта Тюмени и Тюменского района внутри APK. Без ключей,
лимитов и внешних сервисов: данные **OpenStreetMap** под лицензией **ODbL** —
коммерческое использование, офлайн-хранение и встраивание в приложение
разрешены (требуется только указание авторства, оно есть на карте).

| | |
|---|---|
| Формат | PMTiles v3 (один файл), векторные тайлы MVT, схема OpenMapTiles |
| Покрытие | bbox `64.95,56.70,66.35,57.75` — город + Тюменский район |
| Зумы | 0–14 в пакете, до 19 — растягиванием на устройстве |
| Размер | ≈ 40–90 МБ (зависит от даты выгрузки) |
| Работа без сети | полная: тайлы читаются из файла в приложении |
| Вне района | автоматически включается растровый слой OSM (сеть/кеш) |

## 1. Сборка пакета

Нужна **Java 21+** и ~6 ГБ свободного места. Первая сборка — 15–40 минут
(основное время — скачивание выгрузки Уральского ФО), повторные — быстрее.

Windows:

```powershell
.\TaxiDriver\maps\build-pmtiles.ps1
```

Linux / macOS / CI:

```bash
./TaxiDriver/maps/build-pmtiles.sh
```

Скрипт сам скачает planetiler, выгрузку OSM и шрифты, обрежет данные по bbox
и положит результат в `TaxiDriver/Resources/Raw/map/`:

* `tyumen.pmtiles` — карта;
* `font-NotoSansRegular-*.pbf` — шрифты подписей (латиница + кириллица).

Дальше обычная сборка APK — пакет попадёт внутрь автоматически:

```powershell
.\build-driver.ps1
```

Полезные параметры:

```powershell
# детальнее (больше размер, дольше сборка)
.\TaxiDriver\maps\build-pmtiles.ps1 -MaxZoom 15

# не перекачивать выгрузку OSM повторно
.\TaxiDriver\maps\build-pmtiles.ps1 -ReuseOsm

# другой район (запад,юг,восток,север)
.\TaxiDriver\maps\build-pmtiles.ps1 -Bounds "64.5,56.3,67.0,58.2"
```

Файлы пакета намеренно **не хранятся в Git** (бинарники в десятки МБ) —
они собираются перед выпуском версии. Автосборка раз в неделю настроена
в `.github/workflows/build-map-pack.yml`: свежий пакет появляется в
артефактах Actions, его достаточно скачать и положить в
`TaxiDriver/Resources/Raw/map/`.

## 2. Как это работает в приложении

1. При первом запуске пакет копируется из APK в память приложения
   (нужен произвольный доступ к файлу) — один раз, дальше мгновенно.
2. Локальный сервер приложения (`LocalWebServer`) отдаёт карте:
   * `/vector/{z}/{x}/{y}.pbf` — тайлы из PMTiles (`PmTilesArchive`);
   * `/fonts/{fontstack}/{range}.pbf` — шрифты подписей;
   * `/mapinfo.json` — покрытие пакета и готовность.
3. `map.html` опрашивает `/mapinfo.json` и, когда пакет готов, добавляет
   векторные слои поверх растрового. Внутри Тюменского района растр
   отключается (чистая офлайн-карта), за его пределами — включается обратно.
4. Маршрут, машина, пробки и ДТП рисуются поверх — как раньше.

Пакета нет (не собран) → приложение молча работает на прежних растровых
тайлах OSM. Ничего не ломается.

## 3. Домапливание Тюмени и Тюменского района

Точность карты = точность данных OSM. Всё, что вы правите в OSM, попадает
в следующий пересобранный пакет (и в растровые тайлы — за несколько дней).

### С чего начать

1. Зарегистрируйтесь: <https://www.openstreetmap.org/user/new>.
2. Редакторы:
   * **iD** — прямо в браузере, кнопка «Правка» на openstreetmap.org.
     Проще всего, подходит для 90 % задач.
   * **StreetComplete** (Android) — «квесты» прямо на местности: номера домов,
     названия улиц, односторонние, шлагбаумы. Идеально для водителей.
   * **Vespucci** (Android) / **JOSM** (ПК) — для сложных правок:
     запреты поворотов, разделение улиц.
3. Правило номер один: **нельзя копировать данные из Яндекс.Карт, 2ГИС,
   Google и любых закрытых источников** — это нарушение и их лицензий,
   и правил OSM. Источники: собственные наблюдения, GPS-треки, спутниковые
   снимки (в iD включены разрешённые слои), открытые данные администрации.

### Что даёт максимальный эффект для такси

| Приоритет | Что мапить | Теги |
|---|---|---|
| 1 | **Номера домов** новостроек и частного сектора | `addr:housenumber`, `addr:street` |
| 2 | **Дворовые проезды**, подъездные пути к домам | `highway=service`, `service=driveway` |
| 3 | **Шлагбаумы, ворота, заборы** — причина «не могу подъехать» | `barrier=gate` / `lift_gate`, `access=*`, `locked=yes` |
| 4 | **Односторонние** и запреты поворотов | `oneway=yes`, отношение `type=restriction` |
| 5 | **Названия улиц** в новых микрорайонах | `name`, `name:ru` |
| 6 | **Подъезды** и входы | `entrance=yes`, `ref=1..N` |
| 7 | **Ключевые точки**: ЖК, ТРЦ, больницы, вокзалы, Рощино | `place`, `amenity`, `shop`, `building=*` + `name` |
| 8 | **Парковки и площадки** у ТРЦ, вокзала, аэропорта | `amenity=parking`, `access` |
| 9 | **Скорости**, покрытие, сезонные дороги в районе | `maxspeed`, `surface`, `smoothness` |

### Что горит в Тюмени и районе

Проверьте в первую очередь (типовые пробелы):

* новые ЖК — Преображенский, Комарово, Ямальский-2, Восточный-3, Тюменская
  слобода: дома без номеров и внутренние проезды;
* частный сектор и садовые общества (СНТ) — проезды и номера участков;
* сёла Тюменского района: Онохино, Червишево, Богандинский, Винзили,
  Каскара, Ембаево, Боровский, Московский — адреса и подъезды;
* подъезды к аэропорту Рощино, ж/д вокзалу, объездной — актуальность развязок;
* сезонные и грунтовые дороги — `surface`, `smoothness`, проезд в распутицу.

### Рабочий процесс для команды

1. Заведите общий аккаунт-координатор и отмечайте задачи через
   **OSM Notes** (заметки на карте) — водитель ставит точку «нет проезда,
   шлагбаум», редактор вносит правку.
2. Полезные проверки качества: **Osmose** (<https://osmose.openstreetmap.fr/>)
   и **KeepRight** — показывают ошибки геометрии и адресов по региону.
3. Смотреть свежесть данных удобно на <https://www.openstreetmap.org/> —
   правка появляется на растровых тайлах за минуты-часы.
4. Пересобирайте пакет раз в неделю/месяц — тогда офлайн-карта водителей
   всегда актуальна.

### Комментарий к правкам

В поле комментария указывайте суть, например:
`Тюмень, ЖК Преображенский: адреса домов и внутренние проезды (обследование)`.
Не указывайте источником коммерческие карты.

## 4. Обновление пакета

```powershell
.\TaxiDriver\maps\build-pmtiles.ps1 -ReuseOsm:$false   # свежая выгрузка OSM
.\build-driver.ps1                                     # новый APK
```

Водителям достаточно установить новую версию приложения: пакет заменится
целиком (сверяется размер файла), кеш растровых тайлов не трогается.
