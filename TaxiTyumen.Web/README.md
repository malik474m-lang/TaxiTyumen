# TaxiTyumen.Web — веб-порт системы такси «Тюмень»

Полнофункциональный веб-порт оригинальной системы **TaxiService** (.NET 8):
та же бизнес-логика, те же тарифы Тюмени и все четыре роли — но в виде
веб-приложения на **Next.js 16 (App Router) + PostgreSQL (Drizzle ORM) + Tailwind CSS 4**.

## Архитектура: 4 приложения, роли не пересекаются

Как и в оригинале (TaxiClient / TaxiDriver / TaxiOperator / TaxiAdmin),
у каждой роли своё приложение и свой экран входа:

| Приложение | Маршрут | Роль | Порт оригинала |
|---|---|---|---|
| Клиент | `/client` | только client | TaxiClient (MAUI) |
| Водитель | `/driver` | только driver | TaxiDriver (MAUI) |
| Диспетчерская | `/operator` | только operator | TaxiOperator (WPF) |
| Админ | `/admin` | только admin | TaxiAdmin (Blazor) |

`/` — портал-витрина с выбором приложения. Чужой аккаунт система отклоняет.

## Realtime, карты и SMS (итерация 2)

- **Карты OpenStreetMap (Leaflet)** — тёмные тайлы CARTO в тон интерфейса:
  - клиент: маршрут на карте при заказе + живая карта поездки с машинкой водителя
  - водитель: карта доступных заказов (ценники на маркерах) и маршрут текущего
  - диспетчерская: карта автопарка — все водители на линии и свободные заказы
- **GPS-симуляция** (`src/lib/simulate.ts`) — серверный аналог координат из
  MAUI-приложения водителя: машина плавно едет к подаче, затем к финишу
- **Realtime по SSE** (`/api/events` + `src/lib/bus.ts`) — аналог SignalR-хаба:
  in-memory шина публикует события при любых мутациях заказов/водителей/чата,
  клиенты обновляются мгновенно (polling 4 с остаётся резервом)
- **Вход по SMS-коду** (`/api/auth/sms`) — порт `SendSmsCodeAsync` /
  `VerifySmsCodeAsync`: код живёт 5 минут, авто-регистрация клиента по номеру.
  Задайте `SMS_API_ID` (sms.ru) в `.env` для реальных SMS; без ключа —
  демо-режим с показом кода в интерфейсе (как вывод в консоль в .NET-версии)

## Безопасность и качество данных (итерация 3)

- **Серверные сессии** (`src/lib/session.ts`) — HMAC-подписанный токен (аналог JWT
  из .NET-версии). Логин/регистрация/SMS возвращают `token`, клиент шлёт его в
  `Authorization: Bearer`. Каждый мутирующий эндпоинт проверяет роль и владельца:
  - заказ создаёт только его клиент; операторский — только диспетчерская
  - accept/reject — только сам водитель; arrived/start/complete — только назначенный
  - cancel — клиент-владелец или диспетчерская; force-assign — только диспетчерская
  - оценка — только клиент заказа; пополнение баланса/верификация/тарифы/экспорт/статистика — только админ
  - чат пишется только от своего имени
- **Реальный маршрут на карте** — геометрия OSRM (overview=full, десятки-сотни точек)
  сохраняется в заказ (`orders.route_geometry`) и рисуется по дорогам, а не по прямой
- **Пересчёт рейтинга водителя** — оценка клиента обновляет `users.rating`
  средним всем оценённым поездкам
- **ETA подачи** — при живом трекинге показываем «Подача ≈ N мин» (водитель → точка подачи)
- **Экспорт CSV** (порт `Export.razor`) — `/api/export/orders` (UTF-8 BOM, разделитель `;`),
  кнопка «Экспорт CSV» во вкладке заказов админки
- `AUTH_SECRET` в `.env` — секрет подписи токенов (дефолт только для разработки)

## Перенесённая бизнес-логика

- `src/lib/taxi.ts` — `PricingService.cs` + `DistanceCalculator.cs` +
  `OrderNumberGenerator.cs`: расстояние по дорогам через OSRM (fallback Haversine×1.3),
  ночной (23:00–6:00) и пиковый (7–9, 17–19) множители по времени Тюмени (UTC+5),
  минимальный тариф
- `src/app/api/orders/[id]/action/route.ts` — весь жизненный цикл из `OrderService.cs`:
  accept / reject / arrived / start / complete / cancel / force-assign / rate
- Финансы из `BalanceService.cs`: минимальный баланс 100 ₽, комиссия 15 %
  при завершении, штраф 50 ₽ за отказ, история транзакций
- Тарифы из `DataSeeder.cs` (Эконом 49+10/км, Комфорт 99+16, Бизнес 199+25, Минивэн 149+20)
- CI-чат клиент↔водитель вместо SignalR-чата (polling), адреса-подсказки Тюмени

## Запуск

```bash
cp .env.example .env          # укажите свой DATABASE_URL (PostgreSQL)
npm install
npx drizzle-kit push          # создать таблицы
npm run seed                  # нет отдельного скрипта — сиды применяются автоматически
npm run dev                   # http://localhost:3000
```

Сид-данные (тарифы, админ, оператор, демо-водители с машинами) создаются
автоматически при первом обращении к API (`src/lib/seed.ts`).
