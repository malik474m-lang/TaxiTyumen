# TaxiTyumen.Web — веб-порт системы такси «Тюмень»

Полнофункциональный веб-порт оригинальной системы **TaxiService** (.NET 8):
та же бизнес-логика, те же тарифы Тюмени и все четыре роли — но в виде
веб-приложения на **Next.js 16 (App Router) + PostgreSQL (Drizzle ORM) + Tailwind CSS 4**.

## Архитектура: 4 приложения, роли не пересекаются

Как и в оригинале (TaxiClient / TaxiDriver / TaxiOperator / TaxiAdmin),
у каждой роли своё приложение и свой экран входа:

| Приложение | Маршрут | Роль | Порт оригинала |
|---|---|---|---|
| Клиент | `/client` | только client | TaxiClient (MAUI) |
| Водитель | `/driver` | только driver | TaxiDriver (MAUI) |
| Диспетчерская | `/operator` | только operator | TaxiOperator (WPF) |
| Админ | `/admin` | только admin | TaxiAdmin (Blazor) |

`/` — портал-витрина с выбором приложения. Чужой аккаунт система отклоняет.

## Realtime, карты и SMS (итерация 2)

- **Яндекс Карты JS API 2.1** — российская картографическая платформа:
  - клиент: маршрут на карте при заказе + живая карта поездки с машинкой водителя
  - водитель: карта доступных заказов (ценники на маркерах) и маршрут текущего
  - диспетчерская: карта автопарка — все водители на линии и свободные заказы
  - ключ загружается с сервера через `/api/map-config`; задайте `YANDEX_MAPS_API_KEY`
    и ограничьте его доменом в Кабинете разработчика Яндекса
- **GPS-симуляция** (`src/lib/simulate.ts`) — серверный аналог координат из
  MAUI-приложения водителя: машина плавно едет к подаче, затем к финишу
- **Realtime по SSE** (`/api/events` + `src/lib/bus.ts`) — аналог SignalR-хаба:
  in-memory шина публикует события при любых мутациях заказов/водителей/чата,
  клиенты обновляются мгновенно (polling 4 с остаётся резервом)
- **Вход по SMS-коду** (`/api/auth/sms`) — порт `SendSmsCodeAsync` /
  `VerifySmsCodeAsync`: код живёт 5 минут, авто-регистрация клиента по номеру.
  Задайте `SMS_API_ID` (sms.ru) в `.env` для реальных SMS; без ключа —
  демо-режим с показом кода в интерфейсе (как вывод в консоль в .NET-версии)

## Безопасность и качество данных (итерация 3)

- **Серверные сессии** (`src/lib/session.ts`) — HMAC-подписанный токен (аналог JWT
  из .NET-версии). Логин/регистрация/SMS возвращают `token`, клиент шлёт его в
  `Authorization: Bearer`. Каждый мутирующий эндпоинт проверяет роль и владельца:
  - заказ создаёт только его клиент; операторский — только диспетчерская
  - accept/reject — только сам водитель; arrived/start/complete — только назначенный
  - cancel — клиент-владелец или диспетчерская; force-assign — только диспетчерская
  - оценка — только клиент заказа; пополнение баланса/верификация/тарифы/экспорт/статистика — только админ
  - чат пишется только от своего имени
- **Реальный маршрут на карте** — геометрия OSRM (overview=full, десятки-сотни точек)
  сохраняется в заказ (`orders.route_geometry`) и рисуется по дорогам, а не по прямой
- **Пересчёт рейтинга водителя** — оценка клиента обновляет `users.rating`
  средним всем оценённым поездкам
- **ETA подачи** — при живом трекинге показываем «Подача ≈ N мин» (водитель → точка подачи)
- **Экспорт CSV** (порт `Export.razor`) — `/api/export/orders` (UTF-8 BOM, разделитель `;`),
  кнопка «Экспорт CSV» во вкладке заказов админки
- `AUTH_SECRET` в `.env` — секрет подписи токенов (дефолт только для разработки)

## Fleet-функции: смены, опции, автодозвон, аналитика (итерация 4)

- **Смены операторов** (`operator_shifts`, порт `OperatorsController` (`shift/start|end`)) —
  старт/завершение смены в диспетчерской, выработка за смену (создано/завершено заказов),
  считается по `orders.operator_id` за период смены. Чужой роли недоступно
- **Опции заказа** (`order_options`, порт `OrderOption.cs`) — детское кресло +50 ₽,
  животное +70 ₽, встреча с табличкой +100 ₽, крупный багаж +30 ₽, некурящий салон +0 ₽;
  надбавка добавляется к рассчитанной цене при создании (клиент и оператор),
  опции видны чипами в карточках заказа
- **Автодозвон** (`auto_call_settings`, порт `AutoCallService`) — заказы без водителя
  дольше порога эскалируются (красная подсветка в диспетчерской) либо автоназначаются
  ближайшему свободному верифицированному водителю в радиусе (учитываются баланс и отказы).
  Настройки — вкладка «Настройки» в админке. Тик срабатывает по запросам, раз в 10 с
- **Аналитика в админке** — выручка по дням (7 суток) и заказы по часам суток
  (по времени Тюмени UTC+5), лёгкие бар-чарты (`MiniBars`, без внешних зависимостей)

## Серверное брендирование приложений (итерация 5)

Белые метки для трёх приложений — полностью на серверной стороне:

- **Таблица `branding_settings`** — для каждого приложения (`client` / `driver` /
  `operator`): название, кодовое имя, заголовок и подзаголовок экрана входа,
  иконка логотипа, основной цвет, цвет текста на нём, телефон поддержки,
  список преимуществ. Дефолты сидятся автоматически (`src/lib/branding.ts`)
- **SSR-рендер** — страницы `/client`, `/driver`, `/operator` стали серверными
  компонентами (`force-dynamic` + `generateMetadata` из бренда): загружают свой
  бренд из БД и сразу рендерят брендированный HTML; портал `/` собирает
  карточки приложений из тех же данных
- **CSS-переменные бренда** (`--brand`, `--brand-ink`) на корне приложения:
  кнопки, шашки, выделение, скроллбары, свечения перекрашиваются системно
- **Админка → вкладка «Брендинг»** — редактор: название/код, тексты, выбор
  иконки, цвета (color-picker + hex), телефон поддержки, преимущества; живое
  превью экрана входа. `GET /api/branding?app=*` — публично (для входа),
  полный список и `PUT` — только админу, событие `branding` летит в realtime

## Модерация клиентов и панели супер-админа (итерация 6)

- **Вкладка «Клиенты» в админке** (порт `Clients.razor` из Blazor-админки) —
  `/api/clients` отдаёт клиентов с метриками из заказов (поездки, отмены,
  потраченная сумма, последняя поездка), живой поиск по имени/телефону,
  сводка по выборке. Доступ только у ролей admin/superadmin
- **Модерация клиента** — `/api/clients/[id]/action`: блокировка с причиной
  (логин и SMS-вход мгновенно отклоняют заблокированного), разблокировка,
  подтверждение/снятие верификации телефона. Клиента с большой историей
  может блокировать только супер-администратор
- **Вкладка «Бренд сервиса»** (superadmin) — UI поверх `/api/service-brand`:
  название сервиса, город и регион, телефон поддержки, центр карты,
  часовой пояс и подпись в SMS; живое превью для портала
- **Вкладка «Доступ и роли»** (superadmin) — UI поверх `/api/access`:
  переключатели видимости разделов админки для роли admin (раздел «Обзор»
  закреплён), учётные записи администраторов и индикатор целостности
  супер-админа. Раздел «Клиенты» зарегистрирован в общей системе видимости

## Чат водителей автопарка (итерация 7)

- **Таблица `fleet_messages`** — единый канал связи водителей (аналог внутренней
  связи автопарка из диспетчерской): снапшот имени и машины автора
  (`Kia Rio · А123ВС72`), история не зависит от смены авто
- **`/api/fleet-chat`** — GET последних 150 (инкрементально `?after=<ms>`),
  POST только от водителя по его токену, анти-спам 1 сообщение / 1.5 с,
  лимит 500 символов. Читают водители, оператор и админ; клиенты получают 403
- **Приложение водителя** — плавающая кнопка с бейджем непрочитанных
  (localStorage-отметка) и выдвижная панель: свои сообщения справа в цвете
  бренда, чужие сгруппированы по автору. Мгновенные обновления по SSE
  (событие `fleet`), polling 4 с в резерве
- **Диспетчерская** — монитор «Чат водителей» под формой заказа: живой поток
  и модерация (удаление сообщений — operator/admin/superadmin, DELETE ?id=)

## Перенесённая бизнес-логика

- `src/lib/taxi.ts` — `PricingService.cs` + `DistanceCalculator.cs` +
  `OrderNumberGenerator.cs`: расстояние по дорогам через OSRM (fallback Haversine×1.3),
  ночной (23:00–6:00) и пиковый (7–9, 17–19) множители по времени Тюмени (UTC+5),
  минимальный тариф
- `src/app/api/orders/[id]/action/route.ts` — весь жизненный цикл из `OrderService.cs`:
  accept / reject / arrived / start / complete / cancel / force-assign / rate
- Финансы из `BalanceService.cs`: минимальный баланс 100 ₽, комиссия 15 %
  при завершении, штраф 50 ₽ за отказ, история транзакций
- Тарифы из `DataSeeder.cs` (Эконом 49+10/км, Комфорт 99+16, Бизнес 199+25, Минивэн 149+20)
- CI-чат клиент↔водитель вместо SignalR-чата (polling), адреса-подсказки Тюмени

## Запуск

```bash
cp .env.example .env          # укажите свой DATABASE_URL (PostgreSQL)
npm install
npx drizzle-kit push          # создать таблицы
npm run seed                  # нет отдельного скрипта — сиды применяются автоматически
npm run dev                   # http://localhost:3000
```

Сид-данные (тарифы, админ, оператор, демо-водители с машинами) создаются
автоматически при первом обращении к API (`src/lib/seed.ts`).
