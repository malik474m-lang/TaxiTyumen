# Пошаговая настройка TaxiTyumen после установки

Детальная инструкция для администратора, разворачивающего систему
на новом домене.

> **Если установка упала с `1064 ... ключ — в api_settings`:**
> у вас на хостинге **старая версия schema.sql**.
> 1. Удалите `install.lock` через файловый менеджер хостинга.
> 2. Скачайте **новый репозиторий** с GitHub и обновите **все файлы**
>    из `ServerHosting/` одним комплектом, а не только `install.php`.
> 3. Очистите браузерный кеш (Ctrl+F5) и повторите установку.

## Шаг 1. Бренд сервиса

Админка → **«Бренд сервиса»** (только супер-админ).

| Поле | Что указать |
|---|---|
| Название сервиса | Например «НАШЕ Такси» |
| Город | Тюмень / Перевалово / ваш город |
| Регион | Тюменская область |
| Телефон поддержки | +7 (3452) XX-XX-XX |
| Координаты центра | Широта и долгота центра города |
| Часовой пояс | 5 (UTC+5 для Тюмени) |

## Шаг 2. API-ключи

Админка → **«API-ключи»** (только супер-админ).

### DaData (подсказки адресов)

1. Регистрация: [dadata.ru](https://dadata.ru)
2. Личный кабинет → API-ключи
3. Скопируйте значение `Api-Key`
4. Вставьте в поле `dadata` в админке

Бесплатно: 10 000 запросов/сутки.

### TomTom (пробки и маршруты)

1. Регистрация: [developer.tomtom.com](https://developer.tomtom.com)
2. My Apps → Create new app
3. Скопируйте Consumer Key
4. Вставьте в поле `tomtom_traffic` в админке

Бесплатно: 2 500 запросов/сутки.

В админке → **«TomTom»** включите нужные сервисы:
- Traffic Flow — пробки на карте водителя;
- Traffic Incidents — ДТП и перекрытия;
- Routing — маршруты с учётом пробок;
- Matrix Routing — время подачи водителей;
- Search / Reverse Geocoding — поиск адресов.

### Яндекс Карты (карта в приложении клиента)

1. Регистрация: [developer.tech.yandex.ru](https://developer.tech.yandex.ru)
2. Создайте ключ «JavaScript API и HTTP Геокодер»
3. В кабинете Яндекса ограничьте ключ вашим доменом
4. Вставьте в поле `yandex_maps` в админке

Если Яндекс Карты не нужны — в админке → «Геокодинг» выключите
провайдер `yandex`. Приложение клиента автоматически перейдёт на OSM.

### sms.ru (отправка SMS)

1. Регистрация: [sms.ru](https://sms.ru)
2. API-ключ → скопируйте `api_id`
3. Вставьте в поле `sms_ru` в админке

Без ключа коды входа возвращаются в ответе API (демо-режим).

## Шаг 3. Настройки карты

Админка → **«API и сервисы»**.

Проверьте:
- `provider` — `yandex` или `osm`;
- `apiKey` — ключ Яндекса (если выбран);
- `center` — координаты центра города;
- `traffic` / `incidents` — включены, если есть ключ TomTom.

## Шаг 4. Тарифы

Админка → **«Тарифы»**.

По умолчанию созданы 4 тарифа. Для каждого укажите:

| Параметр | Что означает |
|---|---|
| Базовая стоимость | Фиксированная часть цены |
| Цена за км | Стоимость километра |
| Цена за минуту | Стоимость минуты в пути |
| Минимальная цена | Ниже этой суммы не спишется |
| Бесплатное ожидание | Минут бесплатного простоя |
| Платное ожидание | Цена минуты простоя после бесплатного |
| Ночной множитель | Коэффициент ночью (обычно 1.2–1.4) |
| Час пик множитель | Коэффициент в часы пик |
| Комиссия | Процент комиссии системы с водителя |

## Шаг 5. Опции заказа

Админка → **«Опции заказа»**.

Добавьте опции:
- Детское кресло — 50 ₽;
- Перевозка животного — 100 ₽;
- Большой багаж — 50 ₽;
- Некурящий водитель — 0 ₽;
- Кондиционер — 0 ₽.

Опции показываются в приложении клиента и учитываются в цене.

## Шаг 6. Создание персонала

### Водители

Админка → **«Водители»** → «Добавить водителя».

Для каждого водителя:
1. Телефон (логин в приложении);
2. Имя и фамилия;
3. Пароль;
4. Марка, модель, цвет, госномер, год авто;
5. Стартовый баланс (например 500 ₽);
6. Минимальный баланс для приёма заказов (обычно 100 ₽);
7. Отметьте «Верифицирован».

### Операторы

Админка → **«Операторы»** → «Добавить оператора».

Для каждого оператора:
1. Телефон, имя, пароль;
2. Схема оплаты (за заказ / за час / за день / фикс);
3. Ставка.

### Администраторы

Админка → **«Доступ и роли»** (только супер-админ).

Супер-администратор создаётся установщиком и не удаляется.
Обычные админы создаются через раздел «Доступ и роли».

## Шаг 7. Зоны и фиксированные цены (опционально)

Админка → **«Зоны и цены»**.

1. Нарисуйте зону на карте (полигон);
2. Дайте название (например «Аэропорт»);
3. Создайте фиксированную цену между зонами.

Фиксированная цена имеет приоритет над расчётом по километрам.

## Шаг 8. Места и организации

Админка → **«Места и организации»**.

1. Укажите радиус (по умолчанию 25 км);
2. Нажмите «Импортировать организации»;
3. Дождитесь загрузки (1–3 минуты);
4. Адреса определятся автоматически;
5. При необходимости добавьте свои места вручную.

Пассажир сможет искать «Гудвин», «Киномакс», «Рощино» и т.д.

## Шаг 9. Автодозвон (опционально)

Админка → **«Автодозвон»**.

Настройте:
- эскалацию (через сколько минут предлагать другому водителю);
- автоназначение (включить/выключить);
- радиус подбора водителей.

## Шаг 10. SMS-шлюз (опционально)

Админка → **«SMS-шлюз»**.

1. Включите шлюз;
2. Нажмите «Выдать новый токен»;
3. Сохраните токен;
4. Соберите приложение `TaxiSmsGateway` (`build-smsgateway.ps1`);
5. Установите на телефон с SIM-картой;
6. Введите адрес сервера и токен;
7. Нажмите «Запустить шлюз»;
8. Разрешите отправку SMS.

## Шаг 11. Платежи Сбер (опционально)

Админка → **«Платежи Сбер»** (только супер-админ).

1. Получите договор эквайринга Сбера;
2. Введите логин (`...-api`) и пароль;
3. Включите СБП C2B, если одобрен банком;
4. Включите рекуррентные платежи, если одобрены;
5. Укажите `COMPANY_INN` в `config.local.php`.

Без реквизитов кнопка «Карта» в приложении клиента заблокирована.

## Шаг 12. Лицензия

Админка → **«Лицензия»**.

1. Введите ключ лицензии;
2. Нажмите «Активировать».

Без активной лицензии все API возвращают HTTP 403.

## Шаг 13. Сборка мобильных приложений

### Подготовка

В файлах ниже замените `https://taxi.event72.ru` на ваш домен:

```
TaxiClient/Services/ApiService.cs
TaxiClient/Services/BrandingService.cs
TaxiClient/Services/SignalRService.cs
TaxiDriver/Services/ApiService.cs
```

```powershell
powershell -ExecutionPolicy Bypass -File build-client.ps1
```

### Водитель

```powershell
powershell -ExecutionPolicy Bypass -File build-driver.ps1
```

### SMS-шлюз

```powershell
powershell -ExecutionPolicy Bypass -File build-smsgateway.ps1
```

## Шаг 14. Проверка системы

### Через браузер

```
https://ВАШ-ДОМЕН/api/                    — список эндпоинтов
https://ВАШ-ДОМЕН/api/map-config.php     — конфигурация карты
https://ВАШ-ДОМЕН/api/options.php        — опции заказа
```

### Через curl

```bash
# Геокодинг
curl "https://ВАШ-ДОМЕН/api/geocoding.php?q=Тюмень, Республики 52"

# Маршрут
curl "https://ВАШ-ДОМЕН/api/route.php?points=57.1522,65.5272;57.1896,65.3243"

# Оценка цены (все тарифы)
curl "https://ВАШ-ДОМЕН/api/pricing/estimate-all?fromLat=57.1522&fromLng=65.5272&toLat=57.1896&toLng=65.3243"

# Поиск мест
curl "https://ВАШ-ДОМЕН/api/geocoding.php?q=Гудвин"
```

### В приложениях

1. Установите APK клиента и водителя;
2. Зарегистрируйте клиента;
3. Войдите водителем;
4. Создайте тестовый заказ;
5. Примите заказ водителем;
6. Проверьте карту, чат и статусы.

## Шаг 15. Резервное копирование

Настройте на хостинге:
- ежедневный дамп MySQL;
- копию `config.local.php` в надёжном месте;
- копию `uploads/` (логотипы, фото водителей).

## Безопасность после установки

| Действие | Как |
|---|---|
| Удалить install.php | Через файловый менеджер хостинга |
| Проверить install.lock | Должен существовать |
| Установить HTTPS | Let's Encrypt через панель хостинга |
| Ограничить доступ к admin/ | По IP через .htaccess (опционально) |
| Сменить пароль супер-админа | Админка → «Доступ и роли» |
