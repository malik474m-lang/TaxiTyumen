# Установка TaxiTyumen на новый хостинг

Полная инструкция для чистой установки системы такси на новый домен,
без тестовых водителей, операторов и демо-балансов.

## Состав пакета

```
Install-Taxi/
├── install.php          — веб-установщик (удалить после установки!)
├── index.php            — корневая страница (редирект на админку)
├── README.md            — эта инструкция
├── .htaccess            — настройки Apache для корня домена
└── STEPS.md             — пошаговая инструкция с API-ключами
```

## Что вам нужно заранее

1. **Домен** (например `taxi.example.ru`) с настроенным DNS.
2. **Хостинг** с PHP 8.0+ и MySQL 8 (или MariaDB 10.4+).
3. **База MySQL** — можно не создавать заранее, установщик создаст сам
   (пользователь должен иметь право `CREATE`).
4. **Ключи API** (можно добавить позже через админку):
   - DaData — подсказки адресов (бесплатно 10 000 запросов/сутки)
   - TomTom — пробки, маршруты (бесплатно 2 500 запросов/сутки)
   - Яндекс Карты — карта в приложении клиента (бесплатно)
   - sms.ru — отправка SMS (по желанию)
5. **Ключ лицензии** — выданный поставщиком.

## Почему установка может сломаться

**Ошибка:** `SQLSTATE[42000] 1064 ... near 'ключ — в api_settings CREATE TABLE'`

**Причина:** на хостинге лежит **старая версия** `ServerHosting/sql/schema.sql`,
в которой комментарий `-- Сервисы TomTom...` содержит `;`. Установщик разрезает
файл по этой точке с запятой и отправляет в MariaDB невалидный фрагмент.

**Решение:** замените **все** серверные файлы одним комплектом. Обновлять
только `install.php` нельзя — он применит повреждённую старую схему.

## Быстрая установка (5 минут)

### Шаг 1. Загрузите файлы

Загрузите содержимое `ServerHosting/` в корень домена.
В корне должны оказаться папки:

```
api/
admin/
src/
sql/
uploads/
deploy/
config.php
config.protected.php
```

Скопируйте `Install-Taxi/.htaccess` и `Install-Taxi/index.php` в корень домена.
`index.php` нужен, иначе Apache отдаёт 403 при открытии корня домена.

### Шаг 2. Загрузите установщик

Скопируйте `Install-Taxi/install.php` в корень домена.

### Шаг 3. Откройте установщик

Перейдите по адресу:

```
https://ВАШ-ДОМЕН/install.php
```

Заполните форму:
- **MySQL**: хост, порт, имя базы, пользователь, пароль;
- **Домен**: ваш домен без `https://` (например `taxi.example.ru`);
- **Супер-администратор**: логин и пароль (минимум 12 символов).

Нажмите «Установить».

### Шаг 4. Что делает установщик

Автоматически:
- проверяет системные требования (PHP 8+, PDO, mbstring, OpenSSL);
- создаёт базу MySQL;
- применяет полную схему таблиц (40+ таблиц);
- создаёт суперпользователя;
- генерирует секрет подписи токенов;
- создаёт `config.local.php` с вашими реквизитами;
- настраивает `PUBLIC_BASE_URL` и `CORS_ORIGIN` для вашего домена;
- создаёт 4 тарифа (Эконом, Комфорт, Бизнес, Минивэн);
- создаёт `install.lock` — блокирует повторную установку.

НЕ создаёт (в `config.local.php` автоматически записывается
`DEMO_DATA_ENABLED=false`):
- тестовых водителей;
- тестового оператора и демо-администратора;
- тестового клиента;
- демо-балансов.

Флаг действует и после установки: первый вход в админку и первый запрос API
не добавят демо-записи через системный `Seed::ensure()`.

### Шаг 5. Удалите установщик

**Обязательно удалите `install.php` с хостинга после установки!**

### Шаг 6. Войдите в админку

```
https://ВАШ-ДОМЕН/admin/login.php
```

Логин и пароль — те, что вы указали в установщике.

## Настройка после установки

### 1. Бренд сервиса

Админка → **«Бренд сервиса»**:
- название сервиса;
- город;
- телефон поддержки;
- координаты центра города;
- часовой пояс (Тюмень: UTC+5).

### 2. API-ключи

Админка → **«API-ключи»** (только супер-админ):

| Ключ | Где получить | Для чего |
|---|---|---|
| `dadata` | dadata.ru | Подсказки адресов, геокодинг |
| `tomtom_traffic` | developer.tomtom.com | Пробки в приложении водителя |
| `yandex_maps` | developer.tech.yandex.ru | Карта в приложении клиента |
| `sms_ru` | sms.ru | Отправка SMS (коды входа) |
| `opencage` | opencagedata.com | Резервный геокодер |

### 3. Карта

Админка → **«API и сервисы»** → **«Карта»**:
- провайдер: Яндекс Карты или OSM;
- API-ключ Яндекса;
- центр карты (координаты города).

### 4. Тарифы

Админка → **«Тарифы»**:
- созданы 4 тарифа по умолчанию;
- отредактируйте цены под ваш город.

### 5. Опции заказа

Админка → **«Опции заказа»**:
- детское кресло, перевозка животного, багаж и т.д.;
- цена каждой опции.

### 6. Водители

Админка → **«Водители»**:
- создайте водителей (кнопка «Добавить водителя»);
- укажите авто, госномер, телефон;
- задайте стартовый баланс;
- верифицируйте.

### 7. Операторы

Админка → **«Операторы»**:
- создайте операторов диспетчерской;
- настройте схему оплаты и ставки.

### 8. Лицензия

Админка → **«Лицензия»**:
- введите ключ лицензии;
- нажмите «Активировать».

### 9. SMS-шлюз (опционально)

Админка → **«SMS-шлюз»**:
- включите шлюз;
- выпустите токен устройства;
- установите приложение SMS-шлюза на телефон с SIM-картой.

### 10. Места и организации

Админка → **«Места и организации»**:
- нажмите «Импортировать организации» для загрузки ТРЦ, кинотеатров,
  вокзалов, больниц, кафе из OpenStreetMap;
- адреса определятся автоматически.

### 11. Сборка приложений

На компьютере с .NET SDK:

```powershell
powershell -ExecutionPolicy Bypass -File build-client.ps1
powershell -ExecutionPolicy Bypass -File build-driver.ps1
```

Перед сборкой укажите новый домен в:
- `TaxiClient/Services/ApiService.cs` → `BaseAddress`
- `TaxiClient/Services/BrandingService.cs` → `BaseAddress`
- `TaxiClient/Services/SignalRService.cs` → `BaseAddress`
- `TaxiDriver/Services/ApiService.cs` → `BaseAddress`

## Проверка API

После установки проверьте:

```bash
# Доступность API
curl https://ВАШ-ДОМЕН/api/

# Конфигурация карты
curl https://ВАШ-ДОМЕН/api/map-config.php

# Подсказки адресов
curl "https://ВАШ-ДОМЕН/api/geocoding.php?q=Тюмень, Республики 52"

# Маршрут
curl "https://ВАШ-ДОМЕН/api/route.php?points=57.1522,65.5272;57.1896,65.3243"

# Здоровье
curl https://ВАШ-ДОМЕН/api/services.php
```

## Безопасность

После установки:

1. Удалите `install.php`.
2. Убедитесь, что `install.lock` существует.
3. `config.local.php` защищён `.htaccess` от web-доступа.
4. `AUTH_SECRET` в `config.local.php` — не меняйте после установки.
5. Установите HTTPS-сертификат (Let's Encrypt — бесплатно).

## Повторный запуск после ошибки SQL

Если установка остановилась с ошибкой до сообщения «Установка завершена»:

1. замените `install.php` свежей версией из `Install-Taxi/`;
2. убедитесь, что `install.lock` **не создан**;
3. снова откройте `/install.php` и отправьте форму с теми же реквизитами;
4. удалять частично созданную базу не требуется — все таблицы создаются через
   `CREATE TABLE IF NOT EXISTS`, установщик безопасно продолжит с места ошибки;
5. `config.local.php` создаётся только после успешного применения всей схемы.

Новый SQL-парсер учитывает комментарии и кавычки. Точки с запятой внутри
комментариев (`-- ...; ...`) больше не разрывают выражение MariaDB.

## Устранение проблем

| Проблема | Решение |
|---|---|
| «MySQL недоступна» | Проверьте реквизиты в `config.local.php` |
| Пустая страница | Проверьте версию PHP (нужна 8.0+) |
| 404 на /api/ | Проверьте, что `.htaccess` загружен |
| Приложения не подключаются | Проверьте `PUBLIC_BASE_URL` в `config.local.php` |
| Карта не показывает | Добавьте ключ Яндекс Карт в админке |
| Подсказки адресов не работают | Добавьте ключ DaData в админке |
